# Vigie's design system — the written rule

The living mock-up is in the Atelier: **`apps/atelier/design-systeme.html`**
(`http://127.0.0.1:47610/apps/atelier/design-systeme.html`). Its palette is **read live** from the front end by
`tokens.php`; its component examples are reproductions to keep **mirrored** — it is a project discipline: *every visual
change of the front end is carried onto that page in the same delivery*.

## Art direction

1. **Dark sobriety first.** A deep background (`--bg`), panels barely lighter (`--panel`, `--panel-2`), discreet
   borders. Colour is reserved for **meaning** (status, severity) — never decorative. A light theme exists; others may
   be added (radio cards of the Appearance tab).
2. **Status reads without reading.** One scale everywhere: `ok` green, `warn` orange, `error` red, `neutral` without
   colour. Two distinct edges (**D46**): `.modebar` under the header = status of the **application**; the **left**
   edge of a card = status of the **module**. "In progress" is expressed in that same edge, never elsewhere.
3. **An action announces its severity** (**D50**): `fix` green (repairs), `info` blue (informs), `danger` red (touches
   the computer). Resolution button: coloured permanently. Main action: **neutral at rest, its colour on hover**. The
   icon always carries the colour.
4. **The text explains, the tooltip describes** (**D49**): a short value in the card; `help` in the tooltip of the (i);
   `guide` in a fold-out (short) or a window (long). Every `warn`/`error` field offers a **resolution or a guide**.
5. **A technical name is never shown alone** (**D64**): a process name is shown as *Windows description (technical
   name)* — « Processus d'exécution client-serveur (csrss) » — and its row carries a **tooltip** giving the **absolute
   path**, the publisher, the version and the PIDs. Contract: `table.tips`, an array parallel to `table.rows`; the
   tooltip sits on the **row** (`<tr title>`), never on each cell — two nested tooltips fight over the hover.
6. **Icons: our own font** (`vigie-icons.ttf`, **D58**) — generated by `apps/frontend-web/assets/generate-icon-font.py`,
   embedded as a data URI, used through `<span class="vi">&#xE001;</span>`. A missing glyph is **drawn** in the
   generator (one function per icon); no library is imported. SVG is reserved for the **brand**: the tray gauge
   (`generate-icons.py`) and the GitHub logo (`#ghMark`, defined once).

## Components and rules

| Component | Rule | Decision |
|---|---|---|
| Card | header (group, name, status badge, ↻, ⋮), fields, action bar | D49 |
| Card badge | same status as the module edge, icon from the font (✓ ! ✕) | D46/D49 |
| Field | status dot, label, (i), coloured value on the right | D49 |
| Operation in progress | say **what, out of how many, since when**; « … » reserved for this case | D50 |
| Progress block | under its field, only while the operation runs: phase and rank on the total, the current item's title, an overall bar and the item's bar, bytes during a download, elapsed time; the field's value stays short | D50 |
| Operation result | stays visible afterwards (guide: « 1 paquet, réussie ») | D43 |
| Critical action | **two confirmations**: centre/orange then top/red, different labels; reversible when possible (cancellable delay) | D50 |
| Drawers | close cross always at the right edge; Settings = wide drawer with side navigation | D56 |
| Settings | a single ⚙ menu (Notifications, Modules, Appearance, About); no stray button added to the header | D56 |
| Footer | fixed, always visible: version, quick theme, GitHub | — |
| **Nesting** | the frame (border + corners) belongs to the **parent** block, one level only; inside, title band and rows **full width**, separated by a hairline | D88 |
| **Card row** | the **value** answers (short, initial capital, accents), the **colour** alerts, the **detail** explains; a success shows only its date, a path is never a value | D89 |
| **Components** | `UI.bande`, `UI.liste`, `UI.ligne`, `UI.interrupteur`, `UI.etiquette`, `UI.note`, `UI.carte` — each piece written once; a pattern that repeats becomes a component **before** it is copied | D88 |

## Where the values live

- **Front-end palette and type**: the `:root` block of `apps/frontend-web/index.html` — the single definition (D15).
  `tokens.php` serves it to the Atelier.
- **Interface icons**: `apps/frontend-web/assets/generate-icon-font.py` (D58) — the glyph table (name → code point)
  lives there; the generated `.ttf` font is versioned next to it and shown on the Atelier's "Design système" page.
- **Brand (gauge)**: `apps/tray/assets/generate-icons.py` (D01, D37) — mirrored on the "Marque du tray" page and in the
  GDI+ fallback of `tray.ps1`.
- **Tray menu**: the `VigieMenuPalette` class in `apps/tray/tray.ps1`, served by `palette.php`.
